## 剪辑语法参考

### 速度决策
- 升格(慢动作, 40%-80%): 用于情绪高潮、关键动作细节、情感爆发点。要求素材帧率≥60fps
- 降格(快动作, 200%-600%): 用于压缩时间、表现忙碌、过渡段落
- 原速(1x): 正常叙事、对话场景

### 剪辑手法
- 连续剪辑: 默认，保持时空连续
- J-Cut(声音先入): 下一场景的重要声音提前1-2秒切入，制造期待感
- L-Cut(声音延后): 当前场景的声音延续到下一场景，保持情绪连贯
- 交叉蒙太奇: 两条线索交替剪辑，制造紧张感或对比
- 跳切: 同机位删除中间帧，压缩时间或表现焦虑
- 匹配剪辑: 利用相似形状/动作/颜色衔接两个镜头
- 反应镜头插入: 对话中插入听话者的反应，增强情感

### 转场
- 硬切: 默认，最常用
- 叠化(Dissolve): 时间流逝、回忆、情绪过渡
- 闪白/闪黑: 强烈冲击、时间跳跃
- 黑场: 段落结束、情绪沉淀

### 音频处理
- 保留原声: 对话、环境音重要时
- J-Cut/L-Cut: 声音跨镜头衔接
- 配乐覆盖: 情绪段落，用音乐主导
- 音效强化: 动作、转场点

## 任务
为每个镜头做出剪辑决策，输出 JSON 数组:
[
  {
    "shot_id": "S001",
    "keep": true,
    "speed": "1x 或 50% 或 200%",
    "speed_reason": "为什么这样决定",
    "technique": "连续剪辑/J-Cut/L-Cut/交叉/跳切/匹配剪辑/反应镜头插入",
    "technique_reason": "手法选择的理由",
    "transition": "硬切/叠化/闪白/闪黑/黑场",
    "audio": "保留原声/J-Cut/L-Cut/配乐覆盖/音效强化",
    "audio_reason": "音频处理理由",
    "purpose": "这一剪的叙事目的是什么",
    "notes": "其他备注，如'此镜头适合做开场'"
  },
  ...
]

注意:
1. keep=false 表示该镜头被删除；keep=true 表示保留。
2. 相邻镜头的速度和剪辑手法要有节奏变化，避免单调。
3. 情绪高潮前要有铺垫，高潮后要有留白。
4. 对话场景优先考虑反应镜头插入。
5. 如果两个连续镜头情绪反差大、方向跳变或存在越轴风险，考虑用转场过渡。
6. 特殊升格镜头（如子弹时间）不要连续使用 3 个以上。
7. 只输出 JSON，不要其他文字。
